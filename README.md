# Advanced Promodo - KOReader Plugin

A standalone, full-screen Pomodoro timer for KOReader. This plugin transforms your E-ink device into a dedicated productivity and focus tool. 

## Features
- **Standalone UI:** Takes over the full screen, completely distraction-free.
- **Top HUD:** Always displays the current Date and Time at the top.
- **High Precision Timer:** Uses absolute `os.time()` logic to prevent timer drift.
- **Modes:** Easy toggling between Focus Mode and Rest Mode.

## Installation
1. Download the `advanced_promodo.koplugin` folder.
2. Connect your E-reader to your computer.
3. Copy the folder to `koreader/plugins/` directory on your device.
4. Restart KOReader.
5. Go to the Top Menu -> Search/Tools (Magnifying Glass / Gear icon) -> Advanced Promodo Timer -> Open Timer.
