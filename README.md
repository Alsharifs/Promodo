# 🍅 KOReader Pomodoro & Stopwatch Timer Plugin

A clean, minimalist, and feature-rich standalone **Pomodoro and Stopwatch Timer** plugin designed specifically for e-readers (**Kindle**, **Kobo**, etc.) running **KOReader**. 

Optimize your reading and study sessions directly on your e-ink device without distractions.

---

## ✨ Features

- **Dual Operation Modes**:
  - **Pomodoro Mode**: Classic productivity technique with customizable Focus and Rest sessions.
  - **Stopwatch Mode**: Free-running count-up timer starting from `00:00` for open-ended tracking.
- **Live System Clock**: Always displays the current system time (`HH:MM`) at the very top of the screen so you never lose track of time.
- **Adjustable Session Lengths**: Easily increase or decrease Focus and Rest times by 5-minute increments (`Focus ±5`, `Rest ±5`) right from the interface.
- **E-Ink Optimized UI**: Full-screen minimalist design with high-contrast text and responsive touch buttons tailored for e-reader screens.
- **Interactive Touch Controls**: Powered by KOReader's native widget and button layout for smooth responsiveness.

---

## 📥 Installation

1. Download the latest release or clone this repository.
2. Ensure the plugin folder is named exactly **`pomodoro.koplugin`**.
3. Connect your e-reader to your computer.
4. Copy the `pomodoro.koplugin` folder into your KOReader plugins directory:
   - **Kindle / Kobo path:** `koreader/plugins/`
5. Safely eject your device and start KOReader.
6. Go to **Settings (Gear Icon) ⚙️ > Plugin management**, find **Pomodoro Timer**, and enable it.

---

## 🎮 How to Use

1. Open the KOReader top menu, navigate to your tools/menu, and select **Pomodoro Timer > Open Timer**.
2. **In Pomodoro Mode**:
   - Tap **Start** to begin your focus countdown.
   - Use **Focus +5 / Focus -5** or **Rest +5 / Rest -5** to customize your session durations dynamically.
   - When a session ends, it automatically transitions between Focus and Rest states.
3. **In Stopwatch Mode**:
   - Switch to the stopwatch via the mode toggle button for a clean count-up timer.
4. **Exit**: Tap the **Exit** button to close the full-screen timer and return to your book.
